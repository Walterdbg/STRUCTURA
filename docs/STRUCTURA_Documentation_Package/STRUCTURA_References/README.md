## How to use these sources

Read the master specification first. Latest user decisions supersede incompatible earlier prototype constraints. Retain the source-backed operational rules and identifiers; do not revive discarded Odoo/WordPress/Excel deployment choices. These references support the implementation and do not need to be recreated by the next process.
